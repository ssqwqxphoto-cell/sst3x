Сайт полностью статический (один файл `index.html` со всеми фото и видео внутри).

## Как опубликовать на GitHub Pages (бесплатно и навсегда)

### 1. Создай новый репозиторий на GitHub
- Зайди на https://github.com/new
- Название репозитория: например `sst3x` или `portfolio` (любое)
- Выбери **Public**
- **Не** ставь галочки "Add a README", "Add .gitignore" и т.д.
- Нажми **Create repository**

### 2. Загрузи файлы
Скопируй содержимое этой папки в свой новый репозиторий любым удобным способом:

**Вариант А (самый простой — через сайт GitHub):**
1. Открой созданный пустой репозиторий
2. Нажми **uploading an existing file**
3. Перетащи сюда файлы `index.html` и `README.md`
4. Внизу напиши commit message: `Initial commit`
5. Нажми **Commit changes**

**Вариант Б (через терминал / GitHub Desktop):**
```bash
git clone https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/НАЗВАНИЕ_РЕПО.git
cd НАЗВАНИЕ_РЕПО
# скопируй сюда index.html и README.md
git add .
git commit -m "Initial commit - portfolio site"
git push
```

### 3. Включи GitHub Pages
1. В репозитории зайди в **Settings** → **Pages** (слева в меню)
2. В разделе **Source** выбери:
   - Branch: `main`
   - Folder: `/ (root)`
3. Нажми **Save**

Через 1–2 минуты сайт будет доступен по адресу:

```
https://ТВОЙ_ЮЗЕРНЕЙМ.github.io/НАЗВАНИЕ_РЕПО/
```

### Готово!
Ссылка будет работать бесплатно и постоянно.
